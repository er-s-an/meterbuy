# MeterBuy — five-minute product script

Spoken English. About four and a half minutes at a calm pace. Show the product. Do not tour the repository.

## Open on the problem (0:00–0:40)

If you run a small book, you already know the moment. A draft is ready to send. A watchlist needs a price. Someone asks you to forward a note. You can guess, or you can subscribe to a stack of data vendors and still not know which answer was worth paying for.

Personal agents have the same hole. They keep working from whatever they learned last week, because buying a fresh answer means owning the miners, the keys, and the ranking.

## The desk (0:40–1:20)

MeterBuy is the desk I want in that moment. I do not run a miner. I name the job, I set a spend cap, and the desk buys one ranked answer from Telegraph.

There are three jobs, because there are three moments.

A briefing, when I have symbols. A gate, when I have a draft. A note, when I have a question.

The first screen is a meter ticket. I type a symbol and the ticket reprints the miner and the cent. That ticket is not a receipt. I am going to earn a real result on the desk, or I am going to show you an honest stand-in. I will not blur those.

## Buy the briefing (1:20–2:30)

I open the desk. Crypto briefing. Symbols: BTC and ETH. Max spend: five cents. That is enough for two quotes at about a cent each, and it will refuse a third if I get greedy with the cap.

I run it.

What I want you to watch is not the spinner. It is the price table that comes back. The desk ranks the symbols by the unit price it just bought. Then it splits a hundred-dollar purse into equal dollars and tells me which name buys the most units. That recommendation is arithmetic on those prices. If I delete ETH and add SOL and run again, the rank is allowed to change, because the desk bought again. If I only move the basket size, it says so: same prices, not a new purchase.

If this burner can pay, the row is marked paid. You will see the miner, the cost, the time, and a signal hash you can open. If it cannot pay, the banner says the run fell back. The receipt line stays empty. That empty line is the product telling the truth.

## Hold the draft (2:30–3:30)

Second moment. I switch to the fraud gate and load a plain note, the kind I would actually send a landlord. I run it. The stamp is Send or Hold, and it is not a vibe. The desk holds when the bought verdict says AI-generated or likely AI-generated, or when the likelihood is at least 0.62. Otherwise it sends.

Now I load the stiff draft, the one that sounds like a brochure, and I run again. Watch the stamp. It has to be allowed to flip, because the verdict changed. The cues, if any came back, are why. I would rewrite those lines before I send.

## One note, then stop (3:30–4:20)

Last moment. Web intel. I ask a question I would actually look up, and I run it once. The note on screen is the answer that came back, plus one next step: open this source, or refuse to forward it because it named none. I am not chatting. I bought a search and I used it.

## Close (4:20–4:50)

That is the whole product. An operator, a cap, a ranked quote, and one decision that depends on the quote.

You can try it on the demo without a wallet. Mock is labeled. If you want the paid path, the README says how to put Sepolia ETH and test USDC on the burner, then run the same desk on Live. The smoke file in the repo is the latest real attempt, whether it settled or stopped at the payment.

This is Mission 09, a personal agent that pays for fresh intelligence instead of pretending it already knows. We have not submitted it. When the receipt is one you can open, that is the moment to.
